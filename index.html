更新日期：2026年04月19日

1. 关于我们

感谢您选择使用鸿笺（Folio，以下简称“鸿笺”或“本应用”）。

鸿笺是一款运行在 HarmonyOS Next 设备上的 Linkwarden 非官方第三方客户端，由独立开发者 xiebaiyuan（以下简称“我们”或“开发者”）以个人身份免费提供，并以 MIT 协议在 GitHub 开源（项目地址：https://github.com/xiebaiyuan/link-my-harmony）。

鸿笺与 Linkwarden 官方团队（https://github.com/linkwarden/linkwarden）不存在任何隶属、代理或合作关系。本应用不提供任何服务端功能，您的账户、书签、收藏夹、标签等数据均由您自行指定的 Linkwarden 服务器（官方云端或您自托管的实例）承载与管理。

鸿笺用户服务协议（以下简称“本协议”）是开发者与用户（以下简称“您”）关于使用鸿笺所订立的有效协议。

4. 服务内容

鸿笺是运行在 HarmonyOS Next 设备上的 Linkwarden 客户端，通过调用您指定的 Linkwarden 服务器公开的 REST API，为您提供以下功能：

（1） 登录您指定的 Linkwarden 实例（官方云端或自托管）；

（2） 浏览、搜索、按收藏夹或标签过滤您在该实例上已有的书签；

（3） 创建、编辑、删除书签与收藏夹，置顶或取消置顶；

（4） 通过 HarmonyOS 系统分享能力（Share Intent）快速添加书签；

（5） 多语言（简体中文 / English）与浅色、深色、跟随系统等主题偏好设置。

鸿笺本身不运营任何书签服务器，也不收集、转存您的书签内容。您的所有业务数据均由您选择的 Linkwarden 服务器保存与处理；本应用仅在您本机设备上保存登录会话令牌、服务器地址与偏好设置，用于维持您的使用体验。

5. 用户使用规则

5.1 鸿笺不设独立账户体系。您在应用中登录所使用的用户名与密码由您选择的 Linkwarden 服务器托管，登录后产生的会话令牌仅保存在您的设备本地。您应妥善保管您的 Linkwarden 账户凭据，因您个人原因造成凭据泄露、被冒用、盗用或非法使用的，相关风险和损失由您自行承担；

5.2 您在使用鸿笺时，请务必仔细核对 Linkwarden 服务器地址、账户信息及书签 URL 等内容，确保其真实、准确、完整有效；

5.3 请您结合自身需求，选择可信赖的 Linkwarden 实例，并在使用前了解该实例运营方的服务条款与隐私政策；

5.4 您知悉并同意，如因您自身出现输入错误、操作不当、选择了不可靠的服务器，或在第三方服务器上违规使用等情形，您需自行承担所受到的损失及后果。
